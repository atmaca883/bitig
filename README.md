# Bitig — telefon uygulaması

Bu depo, Bitig'in telefon uygulamasının **yalnızca kodunu** içerir ve GitHub Pages ile
https://atmaca883.github.io/bitig/ adresinden yayınlanır.

- Kullanıcı verisi (şifreler, notlar, görevler) bu depoda **yoktur** ve hiçbir zaman buraya gelmez.
- Her kullanıcının kasası kendi cihazında ve kendi Dropbox hesabındaki `Apps/Bitig` klasöründe,
  ana şifresiyle uçtan uca şifreli olarak durur.
- `config.js` içindeki Dropbox "App key" gizli değildir; uygulamayı tanıtan genel bir kimliktir.
